# Day 17 – Git Revisited

This repository is used for the CMSE 202 Day 17 pre-class Git branching and merging practice.

## Branching practice
- `main` is the stable branch.
- `testing` is used to practice isolated changes.
- `hello_world.py` is added on `testing` to demonstrate that a file committed on one branch is not present on `main` until it is merged.

## Merge practice
A separate note is added on `main`, then the `main` branch is merged into `testing` so the testing branch receives those changes.
